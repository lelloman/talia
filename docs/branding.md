# Talìa identity

Status: **E01-04 — Wide gaze** selected as the current mark, 2026-09-18.
The user selected it “for now”; it is the working identity, open to later revision.

The visual family is established by the sibling projects:

- [Crumbles favicon](../../crumbles/crumbles-web/public/favicon.svg): three
  softly rounded, rising blocks.
- [Simple Agents identity](../../simple-agents/docs/branding.md): Short Sweep,
  a compact three-blade mark.
- [ScT identity](../../sct/docs/branding.md): Plain planes, a three-plane chest.

Use the exact shared palette: light `#bfdbfe`, medium `#60a5fa`, strong `#2563eb`.
The common treatment is soft geometry, open space, a transparent standalone
mark, and a white rounded square for app/favicon use. The concepts use a 100×100
viewBox and app tiles with corner radius 22, matching the existing assets.

## Current assets

Use the selected geometry without changing its proportions or color order:
light upper lid, medium lower lid, strong blue pupil. Both lid strokes are 12
units wide with rounded ends; the pupil radius is 12 on the 100×100 viewBox.

| Asset | Usage |
|---|---|
| [brand.svg](../assets/brand/brand.svg) | Canonical transparent mark, README and app identity |
| [favicon.svg](../assets/brand/favicon.svg) | Same mark on a white rounded tile |
| [apple-touch-icon.png](../assets/brand/apple-touch-icon.png) | 180×180 home-screen export |
| [icon-512.png](../assets/brand/icon-512.png) | 512×512 tile export |
| [ic_brand_mark.xml](../assets/brand/ic_brand_mark.xml) | Equivalent Android VectorDrawable, ready for a future client |

These assets are prepared in this repository; no application has been deployed.
The Android vector is a mark, not a complete adaptive launcher-icon configuration.
SVG geometry matches the selected E01-04 concept exactly. Raster exports derive
from `favicon.svg` with `rsvg-convert`; Android paths preserve the same curves,
strokes and circular pupil.

```sh
rsvg-convert -w 180 -h 180 -o assets/brand/apple-touch-icon.png assets/brand/favicon.svg
rsvg-convert -w 512 -h 512 -o assets/brand/icon-512.png assets/brand/favicon.svg
```

## Round 03: selected directions

The user retained E01, M03, D01 and A09 from round 02, requested removal of the
monitor stand, and an alarm in place of the notification dot. The discarded
explorations have been removed. E01-04 is now the current selection.

Open the [current gallery](icon-concepts.html) for 12 refinements each of Eye, Monitor and Dashboard,
and 18 Alarm refinements. Filter by concept, toggle dark surroundings or transparent marks,
and star candidates into a browser-local shortlist. Each mark has transparent
and white-tile SVG downloads plus actual-size 16/24/32/48 px previews.

| IDs | Direction | Comparison sheet |
|---|---|---|
| E01-01–E01-12 | Soft-lidded eye: weight, openness, pupil and gaze variations | [Eye](../assets/icon-concepts/round-3/eye.png) |
| M03-01–M03-12 | Metric monitor without a stand: frame and bar variations | [Monitor](../assets/icon-concepts/round-3/monitor.png) |
| D01-01–D01-12 | Sidebar and two panels: proportions, gaps and corner radii | [Dashboard](../assets/icon-concepts/round-3/dashboard.png) |
| A09-01–A09-18 | Notification card with minimal bell (01–12) or exclamation mark (13–18) | [Alarm](../assets/icon-concepts/round-3/alarm.png) |

The first option in each group is the reference direction: E01 and D01 retain
selected geometry, M03 removes the stand and recenters the mark, and A09 replaces
the dot with a minimal dome. IDs preserve the original selection prefix.

The latest A09 revision removes hanging loops, ringing strokes and separate
rims. Bells use one filled silhouette, optionally with one simple clapper.
Six exclamation alternatives use only a stem and a dot. The other three
concept groups retain their prior geometry.

The gallery embeds sibling marks for comparison; those remain their respective
applications' identities. All Talìa concepts use the exact shared palette.

Source geometry and the HTML gallery are generated by
[generate-icon-concepts.py](../scripts/generate-icon-concepts.py). Regenerate:

```sh
python3 scripts/generate-icon-concepts.py
for concept in eye monitor dashboard alarm; do
  rsvg-convert -o "assets/icon-concepts/round-3/$concept.png" \
    "assets/icon-concepts/round-3/$concept.svg"
done
```

The concept generator updates exploration assets only; it does not overwrite
the selected assets in `assets/brand/`.
